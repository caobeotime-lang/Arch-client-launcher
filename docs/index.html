A launcher that gets
out of your way.

Arch Launcher supports Vanilla, Fabric, Quilt, Forge and NeoForge, installs the right Java for each version, and sets up FPS-boosting mods — so you can open it once and just play. Built for Windows 10/11 and Linux.

Choose your platform

Pick the file for your system. Both are ready to run, so there is nothing to install first. Every download is the latest release on GitHub.

Windows

Windows 10 / 11

No Python needed. Extract the zip and run ArchClient.exe. Windows may show a SmartScreen warning because the file is not code-signed: click “More info → Run anyway”.

  • ArchClient-windows-x64.zip Windows 10 / 11 · 64-bit

Linux

Debian, Ubuntu, Fedora, Arch & more

No Python needed. Pick the format your distro uses.

  • ArchClient-linux-amd64.deb Debian · Ubuntu · Mint · Pop!_OS
  • ArchClient-linux-x86_64.rpm Fedora · openSUSE · Nobara
  • ArchClient-linux-x86_64.pkg.tar.zst Arch · CachyOS · Manjaro · EndeavourOS
  • ArchClient-linux-x86_64.AppImage Any distro · no install needed
  • ArchClient-linux-x86_64.tar.gz Any distro · extract and run
How to install 
sudo apt install ./ArchClient-linux-amd64.deb
sudo dnf install ./ArchClient-linux-x86_64.rpm
sudo pacman -U ArchClient-linux-x86_64.pkg.tar.zst
chmod +x ArchClient-linux-x86_64.AppImage && ./ArchClient-linux-x86_64.AppImage

Zero manual setup

Detects your OS, installs missing libraries, downloads the right Java for each Minecraft version, and sets up your .minecraft folder for you.

Tuned for FPS

One click writes optimized settings and installs performance mods such as Sodium, Lithium and Iris from Modrinth — matched to your version and loader.
